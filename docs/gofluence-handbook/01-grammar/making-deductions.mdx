# Making deductions

## 1. Learning objective

Use clues to explain a problem or a situation, with phrases like **It seems that...** and modals like **must be, might be, could have, can't be**.

## 2. Key concepts

A deduction is a conclusion from **evidence**. You do not know the answer for sure, but the clues point to it.

### Determine the problem

Use these phrases to say what you think the problem is:

- It seems that the server is out of memory.
- It's very likely that the database is slow.
- If you're seeing an error, and the logs are empty, it could mean that the service did not start.
- If the cable is connected, then the problem is the network card.

### Use modal verbs

Use a modal followed by the **infinitive without `to`**.

| Modal | Certainty | Example |
|-------|-----------|---------|
| must be | very sure it is true | It must be a permissions problem. |
| might / may be | possible | It might be a bug in the new version. |
| could be / could have | possible (present or past) | It could have failed during the deploy. |
| can / can't be | can: possible; can't: very sure it is not true | It can't be the network. Other users are online. |

:::tip Present and past
- Present: `must / might / could / can't` + **base verb** (It must be a typo.)
- Past: `must / might / could / can't` + **have + past participle** (It must have been a typo.)
:::

:::note Must for deduction
Here `must` does not mean obligation. It means "I am almost sure". The opposite is `can't`, not `mustn't`.
:::

:::warning Do not use `mustn't` for deductions
- ❌ The file mustn't be on the server.
- ✅ The file **can't** be on the server.
:::

## 5. Common mistakes

| ❌ Wrong | ✅ Correct | Why |
|---------|-----------|-----|
| It must to be a bug. | It must be a bug. | No `to` after a modal. |
| It mustn't be the cable. | It can't be the cable. | Use `can't` for a negative deduction. |
| It must be failed yesterday. | It must have failed yesterday. | Past deduction: modal + `have` + past participle. |
| It could has failed. | It could have failed. | Always `have`, never `has`. |
| It can be the network, I am sure. | It must be the network. | `can` is only possible. For strong certainty use `must`. |

:::danger Spanish speakers
Spanish uses *debe de ser* for deduction, and *debe* also for obligation. In English they are separate: `must be` is a deduction and `have to` is an obligation. For the opposite deduction, say `can't be` (*no puede ser*), never `mustn't be`.
:::

## 6. Practice exercises

### A. Fill in the blanks

Use `must`, `might`, `could` or `can't` with the verb in brackets.

1. The logs show an out-of-memory error. It ______ (be) a memory leak. (very sure)
2. The office is dark and the door is locked. They ______ (be) here. (very sure it is not true)
3. I am not sure why the build is slow. It ______ (be) the new dependency. (possible)
4. The data is gone. Someone ______ (delete) it by mistake. (possible, past)

### B. Rewrite the sentence

Rewrite each sentence with the phrase in brackets.

1. The API is probably down. (It seems that...)
2. I am sure the problem is the DNS. (must)

### C. Speaking prompts

- Your teammate says the website is slow. Give **three deductions** about the cause.
- Describe a problem you solved at work. Which clues helped you?

## 8. Quick recap

- A deduction is a conclusion based on clues.
- `must be` = very sure. `might / could be` = possible. `can't be` = very sure it is not true.
- Past deductions use `have + past participle`.
- Use `It seems that...` and `It's very likely that...` to introduce a problem.

## 9. Review checklist

- [ ] I can explain the difference between `must`, `might` and `can't`.
- [ ] I use `can't`, not `mustn't`, for negative deductions.
- [ ] I can form past deductions with `have + past participle`.
- [ ] I can introduce a problem with `It seems that...`.
- [ ] I can troubleshoot a problem aloud with three deductions.
