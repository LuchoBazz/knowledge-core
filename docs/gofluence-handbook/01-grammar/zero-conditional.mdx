# Zero conditional

## 1. Learning objective

Describe routines, rules and automatic results using **If + present simple, present simple**.

## 2. Key concepts

The zero conditional talks about things that **always happen**. The result is certain. It is the same every time.

```text title="Structure"
If + present simple , present simple
(condition)          (result)
```

| Part | Verb form | Example |
|------|-----------|---------|
| Condition (`if` clause) | present simple | If the team finishes a project, |
| Result (main clause) | present simple | the manager schedules a review meeting. |

:::tip Two ways to build it
You can start with the result. Then you do not need a comma.

- If a new employee joins, an HR team member explains company policies.
- An HR team member explains company policies if a new employee joins.
:::

:::note `If` can mean `when`
In the zero conditional, `if` and `when` mean almost the same thing: every time this happens. Both are correct.
:::

:::warning Do not use `will` in either clause
Use the present simple in **both** parts. `will` is for the [first conditional](./first-conditional.mdx), which talks about one possible future situation.
:::

### Zero vs first conditional

| | Zero conditional | First conditional |
|---|---|---|
| Meaning | Always true, routine | One possible future event |
| Structure | If + present, present | If + present, will + base verb |
| Example | If the build fails, the pipeline sends an alert. | If the build fails today, I will fix it tonight. |

## 5. Common mistakes

| ❌ Wrong | ✅ Correct | Why |
|---------|-----------|-----|
| If the team will finish a project, the manager schedules a review. | If the team **finishes** a project, the manager schedules a review. | No `will` after `if`. |
| If a new employee joins, an HR member **explain** policies. | …an HR member **explains** policies. | Third person singular needs `-s`. |
| If the team finishes a project the manager schedules a review. | If the team finishes a project**,** the manager schedules a review. | Use a comma when `if` comes first. |
| If the build fails, it is sending an alert. | If the build fails, it **sends** an alert. | Routines use the present simple, not the continuous. |

:::danger Spanish speakers
Spanish often uses a future form in the result (*Si termina, enviará…*). In the English zero conditional, never use `will`. Keep **present + present**.
:::

## 6. Practice exercises

### A. Fill in the blanks

1. If a client ______ (sign) the contract, the sales team ______ (send) a welcome kit.
2. If a new employee ______ (join), an HR member ______ (explain) the policies.
3. If the server ______ (be) down, the monitoring tool ______ (alert) the team.
4. The manager ______ (schedule) a review meeting if the team ______ (finish) a project.

### B. Rewrite the sentence

Rewrite each sentence with the `if` clause **first**.

1. The bot blocks the merge if a pull request has no approval.
2. The team celebrates if a release goes well.

### C. Speaking prompts

- Describe **three automatic rules** in your team using `If … , …`.
- What happens at your company if a new person joins?

## 8. Quick recap

- Zero conditional = **If + present simple, present simple**.
- Use it for routines, rules and automatic results.
- `if` can be replaced by `when`.
- No `will` in either clause.
- Use a comma when the `if` clause comes first.
