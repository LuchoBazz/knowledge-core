# Manage scope creep

## 1. Learning objective

Explain scope creep and use infinitives of purpose to set goals, give reasons and communicate limits.

## 2. Key concepts

**Scope creep** happens when the requirements of a project in progress grow, but the schedule, budget and other resources do not change. If nobody manages it, the project often fails. You can avoid it with **clear goals** and **clear limits**.

To set goals and limits, use **infinitives of purpose**. They give the **reason** for an action.

```text title="Structure"
action + to + base verb
action + so as to + base verb
action + in order to + base verb
```

| Form | Example |
|------|---------|
| to + verb | Many young entrepreneurs join the tech tour **to meet** new investors. |
| so as to + verb (formal) | The warehouse officer visited different sites **so as to ensure** stocks are complete. |
| in order to + verb (formal) | We wrote a change request **in order to protect** the budget. |
| negative | We froze the scope **so as not to** delay the launch. |

:::tip Four rules
1. The infinitive can come **before or after** the main verb.
2. It works with main verbs in **different tenses**.
3. In formal English, `so as to` and `in order to` mean the same as `to`.
4. For the negative, put `not` **before** `to`: `in order not to`, `so as not to`.
:::

```text title="Before or after the main verb"
To cut costs for the company, all contract analysts will review documents.
All contract analysts will review documents to cut costs for the company.
```

:::warning Not `for` + verb
Do not say `for to` or `for` plus a verb to give a purpose. Say `to cut costs`, not `for cut costs` or `for to cut costs`.
:::

:::danger Do not put `not` after `to`
Say `in order not to delay` or `so as not to delay`. Avoid `in order to not delay` in formal project documents. Plain `to` has no formal negative, so switch to `so as not to` or `in order not to`.
:::

## 5. Common mistakes

| ❌ Wrong | ✅ Correct | Why |
|---------|-----------|-----|
| We froze the scope for avoid delays. | We froze the scope **to avoid** delays. | Purpose = `to` plus base verb. |
| We froze the scope in order **to not** delay. | ...in order **not to** delay. | `not` goes before `to` in the formal negative. |
| We wrote a plan so as ensuring quality. | We wrote a plan so as **to ensure** quality. | `so as to` plus base verb, not `-ing`. |
| We use this tool in order for save time. | We use this tool **in order to save** time. | Do not use `for` plus a verb. |
| To avoid scope creep we defined goals. | To avoid scope creep**,** we defined goals. | Use a comma when the infinitive clause comes first. |

:::note Spanish speakers
In Spanish we say *para evitar*, *con el fin de evitar*. In English, `to avoid` is enough. Never translate *para* as `for` before a verb.
:::

## 6. Practice exercises

### A. Fill in the blanks

1. We define clear goals ______ avoid scope creep.
2. The manager wrote a change request in ______ to protect the budget.
3. We froze the scope so ______ not to delay the launch.
4. ______ cut costs, all analysts will review documents.

### B. Rewrite the sentence

Rewrite each sentence with an infinitive of purpose. Use the word in brackets.

1. We held a weekly meeting. We wanted to check the progress. (to)
2. We limited the features. We did not want to exceed the budget. (so as not to)
3. The PM met the client. She wanted to explain the limits. (in order to)

### C. Speaking prompts

- Have you experienced scope creep in a project? What problems did it cause?
- Explain three ways to avoid scope creep. Use `to`, `so as to` and `in order to`.

## 8. Quick recap

- Scope creep = project requirements grow without changing schedule or budget.
- Infinitives of purpose give the reason: `to`, `so as to`, `in order to`.
- Use `so as to` and `in order to` in formal English.
- Negative: `in order not to`, `so as not to`.
- The infinitive clause can come before or after the main verb.
