# Present a project status report

## 1. Learning objective

Give a short status report that covers three things: progress, important events and the timeline.

## 2. Key concepts

A status report answers three questions.

| Part | Question | Typical tense |
|------|----------|---------------|
| Progress | Where are we now? | present simple, present continuous, present perfect |
| Important events | What happened recently? What is coming? | past simple, first conditional |
| Timeline | When did we start? Are we on time? | past simple, present simple |

```text title="Structure of a status report"
1. Progress   - So far, we are done with ...
2. Events     - Just last week, we ...
3. Timeline   - We started in ... / We are delayed by ... / We are ahead by ...
```

:::tip Match the tense to the time
- **Right now**: `We are currently in the testing stage.` (present continuous)
- **Up to now**: `So far, we are done with the first two steps.`
- **Finished past event**: `Just last week, we reassessed our timeline.` (past simple)
- **Possible future**: `If the trial run goes well, this week will be a landmark.`
:::

:::note Time words
Use `recently`, `just last week`, `so far` and `to date` to place events in time. `Recently` with the past simple is very common in reports.
:::

:::warning Delay or advance: say how much
Always give the size of the change: `delayed by three weeks`, `ahead by a month`. Use `due to` plus a noun for the reason and `because` plus a clause.
:::

## 5. Common mistakes

| ❌ Wrong | ✅ Correct | Why |
|---------|-----------|-----|
| We are in the testing stage since June. | We **have been** in the testing stage **since** June. | Use the present perfect with `since`. |
| Just last week we have reassessed the timeline. | Just last week, we **reassessed** the timeline. | A finished time (`last week`) needs the past simple. |
| We are delayed **for** three weeks. | We are delayed **by** three weeks. | Use `by` for the size of the delay. |
| **Because of** everything went well, we are ahead. | **Because** everything went well, we are ahead. | `Because of` plus noun. `Because` plus clause. |
| If the trial run will go well, ... | If the trial run **goes** well, ... | No `will` after `if`. |

:::danger Spanish speakers
`Actually` does not mean *actualmente*. Use `currently` or `at the moment` for *actualmente*.
:::

## 6. Practice exercises

### A. Fill in the blanks

1. ______ far, we are done with the first two steps.
2. We are ______ in the testing stage. (right now)
3. ______ to some technical difficulties, we are delayed by three weeks.
4. We are ahead ______ a month.

### B. Rewrite the sentence

Rewrite each sentence with the phrase in brackets.

1. The team reassessed the timeline. (Just last week)
2. Everything went according to plan, so we are early. (Because)

### C. Speaking prompts

- Give a 30-second status report about a project you know. Cover progress, one event and the timeline.
- Explain a delay: how long, and why.

## 8. Quick recap

- A status report has three parts: progress, important events, timeline.
- Use `so far`, `currently` and `to date` for progress.
- Use the past simple with `just last week` and `recently`.
- Say the size of the delay: `delayed by` or `ahead by`.
- `Due to` plus noun. `Because` plus clause.

## 9. Review checklist

- [ ] I can describe progress with `so far` and `currently`.
- [ ] I can talk about a recent event in the past simple.
- [ ] I can say if a project is delayed or ahead.
- [ ] I know when to use `due to` and `because`.
- [ ] I can give a 30-second status report aloud.
