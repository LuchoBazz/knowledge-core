# Cheat Sheet

A one-page review. Read it once a week.

## Conditionals

| Type | Structure | Use | Example |
|------|-----------|-----|---------|
| Zero | If + present, present | Routines, things that always happen | If a new employee joins, HR explains the policies. |
| First | If + present, will + base verb | A possible future event | If the client signs, we will deliver next month. |

## Modals: the certainty ladder

| Certainty | Present / future | Past |
|-----------|------------------|------|
| 100% sure it is true | must be | must have + past participle |
| Possible (50%) | may / might / could be | may / might / could have + past participle |
| 100% sure it is false | can't be | can't have + past participle |

:::tip General rules
- Modals never change form (no `-s`).
- Modal + **base verb**: `She can help`, not `She can to help`.
- Only one modal per verb.
- Past: modal + `have` + past participle.
:::

| Meaning | Modal | Example |
|---------|-------|---------|
| Obligation | must | You must show an ID. |
| Confident guess | must | She is absent. She must be sick. |
| Suggestion | should / could / might want to | We should negotiate a higher price. |
| Possibility | can / could / may / might | Her tardiness could become an issue. |

## Present perfect vs simple past

| | Present perfect | Simple past |
|---|---|---|
| Form | have / has + past participle | verb + `-ed` or irregular form |
| Time | Unfinished time or connected to now | Finished time, not connected to now |
| Example | I have noticed a problem with the printer. | We started in June. |
| Signals | already, yet, just, ever, never, since, for | yesterday, last week, in 2008, ago |

## Small but useful

| Topic | Rule |
|-------|------|
| `by` + verb | Always `-ing`: It saves us time by automating tasks. |
| Infinitive of purpose | To / so as to / in order to + base verb. Negative: in order not to. |
| made of / made from | `of` = material does not change. `from` = material changes. |
| Causatives | make = force, let = allow, have = ask, get = persuade, help = assist. |
| Comparatives | friendlier than, more experienced than, as motivated as |
| Object pronouns | me, you, him, her, it, us, them (after a verb or a preposition) |
