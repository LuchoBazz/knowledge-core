Zero conditional

1. Learning objective​

Describe routines, rules and automatic results using If + present simple, present simple.

2. Key concepts​

The zero conditional talks about things that always happen. The result is certain. It is the same every time.

Structure
If + present simple , present simple
(condition)          (result)
PartVerb formExample
Condition (if clause)present simpleIf the team finishes a project,
Result (main clause)present simplethe manager schedules a review meeting.
Two ways to build it

You can start with the result. Then you do not need a comma.

  • If a new employee joins, an HR team member explains company policies.
  • An HR team member explains company policies if a new employee joins.
If can mean when

In the zero conditional, if and when mean almost the same thing: every time this happens. Both are correct.

Do not use will in either clause

Use the present simple in both parts. will is for the first conditional, which talks about one possible future situation.

Zero vs first conditional​

Zero conditionalFirst conditional
MeaningAlways true, routineOne possible future event
StructureIf + present, presentIf + present, will + base verb
ExampleIf the build fails, the pipeline sends an alert.If the build fails today, I will fix it tonight.

3. Vocabulary & useful phrases​

EnglishMeaning / Spanish hintExample sentence
routinerutinaOur weekly review is a routine for the whole team.
schedule (a meeting)programar, agendarThe manager schedules a review meeting.

4. Examples in a workplace context​

  • Meetings
  • Onboarding
  • Engineering
Team rules
If the team finishes a project, the manager schedules a review meeting.
If someone is absent, they read the meeting notes later.
HR process
If a new employee joins, an HR team member explains company policies.
If a new developer joins, the team lead gives them access to the repositories.
Code review & CI
If a pull request has no approval, the bot blocks the merge.
If the tests fail, the pipeline sends a message to the team channel.
💬 Stand-up chat

Ana: What happens if a pull request stays open for two days?

Leo: If a pull request stays open for two days, the bot reminds the reviewers.

Ana: Great. And if nobody answers?

Leo: If nobody answers, the tech lead picks a reviewer.

5. Common mistakes​

❌ Wrong✅ CorrectWhy
If the team will finish a project, the manager schedules a review.If the team finishes a project, the manager schedules a review.No will after if.
If a new employee joins, an HR member explain policies.…an HR member explains policies.Third person singular needs -s.
If the team finishes a project the manager schedules a review.If the team finishes a project**,** the manager schedules a review.Use a comma when if comes first.
If the build fails, it is sending an alert.If the build fails, it sends an alert.Routines use the present simple, not the continuous.
Spanish speakers

Spanish often uses a future form in the result (Si termina, enviará…). In the English zero conditional, never use will. Keep present + present.

6. Practice exercises​

A. Fill in the blanks​

  1. If a client ______ (sign) the contract, the sales team ______ (send) a welcome kit.
  2. If a new employee ______ (join), an HR member ______ (explain) the policies.
  3. If the server ______ (be) down, the monitoring tool ______ (alert) the team.
  4. The manager ______ (schedule) a review meeting if the team ______ (finish) a project.

B. Rewrite the sentence​

Rewrite each sentence with the if clause first.

  1. The bot blocks the merge if a pull request has no approval.
  2. The team celebrates if a release goes well.

C. Speaking prompts​

  • Describe three automatic rules in your team using If … , ….
  • What happens at your company if a new person joins?

D. Quick quiz​

Choose the correct zero conditional.

7. Answer key​

Show answers

A.

  1. signs, sends
  2. joins, explains
  3. is, alerts
  4. schedules, finishes

B.

  1. If a pull request has no approval, the bot blocks the merge.
  2. If a release goes well, the team celebrates.

C. Answers vary. Check that both verbs are in the present simple and that you use a comma after the if clause.

8. Quick recap​

  • Zero conditional = If + present simple, present simple.
  • Use it for routines, rules and automatic results.
  • if can be replaced by when.
  • No will in either clause.
  • Use a comma when the if clause comes first.

9. Review checklist​

  • I can write the structure from memory.
  • I can give three workplace examples.
  • I know the difference between zero and first conditional.
  • I use the third person -s correctly.
  • I can say my examples aloud without hesitation.
