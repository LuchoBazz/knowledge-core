# GoFluence English Handbook

A personal handbook to review each topic from my virtual classes with a tutor. Language level: **B1–B2**. Focus: **workplace English**.

## How to use this handbook

1. **Before class:** skim the topic's *Learning objective* and *Vocabulary*.
2. **After class:** read the topic page, then add your own notes in [Class Notes](./class-notes.mdx).
3. **Next day:** do the *Practice exercises* without looking at the answers.
4. **Every week:** reread the [Cheat Sheet](./cheat-sheet.mdx) and the [Common Mistakes](./common-mistakes.mdx).
5. **When in doubt:** search a word in the [Glossary](./glossary.mdx) or use the search bar.

## Every topic follows the same 9 steps

| # | Section | What to do |
|---|---------|-----------|
| 1 | Learning objective | Know the goal |
| 2 | Key concepts | Read the rule in simple words |
| 3 | Vocabulary & phrases | Learn the table |
| 4 | Workplace examples | Copy the patterns |
| 5 | Common mistakes | Spot ❌ and ✅ |
| 6 | Practice exercises | Write and speak |
| 7 | Answer key | Check (hidden in a collapsible) |
| 8 | Quick recap | Review in 1 minute |
| 9 | Review checklist | Tick when you are confident |
