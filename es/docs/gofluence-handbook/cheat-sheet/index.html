Cheat Sheet

A one-page review. Read it once a week.

Conditionals​

TypeStructureUseExample
ZeroIf + present, presentRoutines, things that always happenIf a new employee joins, HR explains the policies.
FirstIf + present, will + base verbA possible future eventIf the client signs, we will deliver next month.

Modals: the certainty ladder​

CertaintyPresent / futurePast
100% sure it is truemust bemust have + past participle
Possible (50%)may / might / could bemay / might / could have + past participle
100% sure it is falsecan't becan't have + past participle
General rules
  • Modals never change form (no -s).
  • Modal + base verb: She can help, not She can to help.
  • Only one modal per verb.
  • Past: modal + have + past participle.
MeaningModalExample
ObligationmustYou must show an ID.
Confident guessmustShe is absent. She must be sick.
Suggestionshould / could / might want toWe should negotiate a higher price.
Possibilitycan / could / may / mightHer tardiness could become an issue.

Present perfect vs simple past​

Present perfectSimple past
Formhave / has + past participleverb + -ed or irregular form
TimeUnfinished time or connected to nowFinished time, not connected to now
ExampleI have noticed a problem with the printer.We started in June.
Signalsalready, yet, just, ever, never, since, foryesterday, last week, in 2008, ago

Small but useful​

TopicRule
by + verbAlways -ing: It saves us time by automating tasks.
Infinitive of purposeTo / so as to / in order to + base verb. Negative: in order not to.
made of / made fromof = material does not change. from = material changes.
Causativesmake = force, let = allow, have = ask, get = persuade, help = assist.
Comparativesfriendlier than, more experienced than, as motivated as
Object pronounsme, you, him, her, it, us, them (after a verb or a preposition)
