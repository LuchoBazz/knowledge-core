First conditional

Assumptions

The class notes cover three ideas: the first conditional, phrases to discuss business options, and phrases to make suggestions. This page puts them together because you often use them in the same meeting.

1. Learning objective​

Talk about a possible action and its likely result with If + present simple, will + base verb. Then use set phrases to discuss options and make suggestions.

2. Key concepts​

The first conditional talks about a possible action and its likely result in the future.

Structure
If + present simple , will + base verb
(condition)           (result)
PartVerb formExample
Condition (if clause)present simpleIf the client signs the contract,
Result (main clause)will + base verbwe will deliver the order next month.
Two ways to build it

You can put the result first. Then you do not need a comma.

  • If we finalize the project details today, we will assign tasks to the team tomorrow.
  • We will assign tasks to the team tomorrow if we finalize the project details today.
No will in the if clause

Use the present simple after if, even when you talk about the future. Say If the client signs, not If the client will sign.

Discussing business options​

Use conditionals to compare options and their consequences.

  • If we implement a workforce reduction plan, our company will be able to cope with the global recession.
  • If we freeze hiring, we won't have to fire some of our best employees.
  • If we do this, then the company will lose a great deal of talent.

You can add then to the result to make it stronger: If we do this, then the company will lose…

Phrases to suggest an option​

PhraseExample
What if ...What if we consider outsourcing overseas?
An alternative ...An alternative could be stopping all salary increases and bonuses.
How about ...How about we implement cost-cutting strategies?

Making suggestions​

Direct phrases

I suggest ..., We suggest ... and Let's ... are direct and clear.

Modals and question words soften a suggestion and sound more polite.

PatternExample
You/We/They could + base verbWe could move the deadline to Friday.
You/We/They might (not) want to + base verbYou might want to review the budget first.
What/How about + verb-ing?How about reviewing it together?
Why don't/doesn't + subject + base verb?Why don't we ask the client for more time?
Why not + base verb?Why not start with a small pilot?

4. Examples in a workplace context​

  • Formal
  • Informal
Email to client
Dear Ms. Lopez,

If you sign the contract by Friday, we will deliver the order next month.
If we receive the final specifications today, we will start the work on Monday.

Best regards,
Daniel
Slack message
If the tests pass today, we will deploy tomorrow morning.
If you need help with the review, ping me and I will join the call.
💬 Budget meeting

Manager: We need to reduce costs this quarter. What are our options?

Sara: If we freeze hiring, we won't have to fire anyone.

Tom: True, but if we do this, then the team will have too much work.

Sara: What if we consider outsourcing the support tasks?

Manager: Good idea. How about we ask two vendors for a quote?

Team suggestions
Let's review the plan on Monday.
We could split the project into two phases.
You might want to share the report before the meeting.
Why don't we ask the client for feedback?

5. Common mistakes​

❌ Wrong✅ CorrectWhy
If the client will sign, we will deliver the order.If the client signs, we will deliver the order.No will in the if clause.
If we freeze hiring, we don't have to fire anyone next month.If we freeze hiring, we won't have to fire anyone.Use will or won't in the result for a future consequence.
If we will finalize the details, we assign tasks.If we finalize the details, we will assign tasks.Present simple in the if clause, will in the result.
Why we don't ask the client?Why don't we ask the client?Question word order: auxiliary before subject.
How about to implement a new plan?How about implementing a new plan?Use verb-ing after How about.
Spanish speakers

The idea is about the future, so many Spanish speakers add will after if (If the client will sign…). In English, never use will right after if in the first conditional. Use the present simple.

6. Practice exercises​

A. Fill in the blanks​

  1. If the client ______ (sign) the contract, we ______ (deliver) the order next month.
  2. If we ______ (freeze) hiring, we ______ (not / have) to fire anyone.
  3. If we ______ (finalize) the details today, we ______ (assign) tasks tomorrow.
  4. If we ______ (set) the price too low, we ______ (lose) money.

B. Rewrite the sentence​

Rewrite each sentence as a suggestion with the phrase in brackets.

  1. We should outsource the support tasks. (What if ...)
  2. Stop all salary increases for a year. (An alternative ...)
  3. We can ask the client for more time. (Why don't we ...?)
  4. You should review the budget first. (You might want to ...)

C. Speaking prompts​

  • Your team has a tight deadline. Give two options using If … will ….
  • Suggest a solution to a problem at work using What if, How about and Let's.

D. Quick quiz​

Choose the correct first conditional.

7. Answer key​

Show answers

A.

  1. signs, will deliver
  2. freeze, won't have
  3. finalize, will assign
  4. set, will lose

B. Possible answers:

  1. What if we outsource the support tasks?
  2. An alternative could be stopping all salary increases for a year.
  3. Why don't we ask the client for more time?
  4. You might want to review the budget first.

C. Answers vary. Check that the if clause uses the present simple and the result uses will or won't.

8. Quick recap​

  • First conditional = If + present simple, will + base verb.
  • It talks about a possible future action and its likely result.
  • Never use will in the if clause.
  • Use What if, An alternative and How about to discuss business options.
  • Use Let's, could, might want to, Why don't we and Why not to make suggestions.

9. Review checklist​

  • I can write the structure from memory.
  • I can give three workplace examples with If … will ….
  • I know the difference between the zero conditional and the first conditional.
  • I can suggest an option with What if, How about and An alternative.
  • I can make a polite suggestion with could or might want to.
