How to give and ask for feedback

1. Learning objective​

Ask for and give feedback politely using verbs for opinions and modals such as would, could and I'd like to.

2. Key concepts​

Feedback is information about someone's work. Good feedback is clear, kind and useful.

Verbs to ask for or give an opinion​

You can talk about what you think or feel.

AskGive
What did/do you think of... ?I think (that) ...
How do you feel about… ?I feel (that) ...

Modals to be polite​

PhraseUse
I'd like to know what (else) I can improve on.Ask for feedback
How (else) can I improve… ?Ask for feedback
I could see that…Give an observation
It would help if…Give a suggestion
It would also be good if…Add another suggestion
Say what you saw, then what would help

First, describe what you noticed: I could see that the slides were clear. Then suggest a change: It would help if you added the main numbers.

else asks for more

What else can I improve on? and How else can I improve? ask for extra feedback after the first answer. They show you want to learn more.

would makes advice softer

Compare: You need to speak slower. (direct) and It would help if you spoke more slowly. (polite). After It would help if, use the past simple: you spoke, you added.

4. Examples in a workplace context​

  • Asking for feedback
  • Giving feedback
After a presentation
What did you think of my presentation?
I'd like to know what else I can improve on.
How else can I improve next time?
Code review comment
I could see that the function is well tested.
It would help if you added a short comment about the edge case.
It would also be good if the variable names were clearer.
💬 One-to-one with a manager

Julia: What did you think of my demo yesterday?

Manager: I think it was clear. I could see that you prepared a lot.

Julia: Thanks. I'd like to know what else I can improve on.

Manager: It would help if you shared the results earlier in the demo.

Julia: Good idea. How else can I improve?

Manager: It would also be good if you invited the clients to ask questions.

Email asking for feedback
Subject: Feedback on the project report

Hi Daniel,

I have just sent the project report. How do you feel about the structure?
I'd like to know what I can improve on. Any comments are welcome.

Thank you,
Rosa

5. Common mistakes​

❌ Wrong✅ CorrectWhy
What do you think about my work? (about a finished event)What did you think of my work?Use the past for a finished event, like a presentation yesterday.
I would like know what to improve.I'd like to know what to improve.would like + to + base verb.
It would help if you will add more data.It would help if you added more data.After It would help if, use the past simple.
How can I improve else?How else can I improve?else goes after the question word.
You are wrong, change this.It would help if you changed this.Direct commands sound harsh.
Spanish speakers

In Spanish we say Me gustaría saber… with a simple verb. In English, use I'd like to know… with to. Also, do not use will after if: Ayudaría si agregas… becomes It would help if you added….

6. Practice exercises​

A. Fill in the blanks​

  1. What ______ you think of my report? (it was yesterday)
  2. I'd like ______ know what else I can improve on.
  3. It would help if you ______ (add) more examples.
  4. How ______ can I improve my English at work?

B. Rewrite the sentence​

Make each sentence more polite.

  1. Your slides are too long.
  2. Send the summary earlier.

C. Speaking prompts​

  • Ask your manager for feedback after a meeting. Use What else can I improve on?.
  • Give feedback to a teammate with I could see that… and It would help if….
  • Say one positive and one improvement point about a colleague's presentation.

D. Quick quiz​

Choose the polite suggestion.

7. Answer key​

Show answers

A.

  1. did
  2. to
  3. added
  4. else

B. Suggested answers:

  1. It would help if the slides were shorter.
  2. It would help if you sent the summary earlier.

C. Answers vary. Check the modals, the past simple after if, and polite tone.

D. Option 2.

8. Quick recap​

  • Ask with What did you think of…?, How do you feel about…? and How (else) can I improve…?.
  • Give an opinion with I think (that)… or I feel (that)….
  • Use I could see that… to describe what you noticed.
  • Use It would help if… + past simple for suggestions.
  • else asks for more feedback.

9. Review checklist​

  • I can ask for feedback in three ways.
  • I can give feedback with It would help if….
  • I use the past simple after It would help if.
  • I can use else to ask for more.
  • My feedback sounds polite and clear.
